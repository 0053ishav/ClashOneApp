# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use the repository's private security reporting mechanism when available. If that is unavailable, contact the maintainers privately before disclosing the issue publicly.

Include:

- affected version or commit
- reproducible steps
- impact
- relevant logs or proof of concept

Redact player identifiers, credentials, API keys, tokens, and other private information.

## Scope

Security reports involving authentication, secrets, API access, account data, payments, notification data, or backend endpoints are especially important.
